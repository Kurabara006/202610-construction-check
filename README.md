# 現場チェック記録

静的なウェブアプリです。写真を撮影（または選択）しコメントを付けて記録し、一覧として印刷・PDF 保存や JSON エクスポートができます。

## データの蓄積方針

| 方式 | 用途 |
|------|------|
| **IndexedDB（デフォルト）** | 作業中はブラウザ内に自動保存。サーバー不要。 |
| **JSON エクスポート / インポート** | バックアップ、別端末への引き継ぎ、共有。 |
| **一覧出力（HTML 印刷）** | 報告書・PDF 用の最終成果物。 |

サーバー側 DB は使わないため、ホスティングは GitHub Pages や Netlify など静的ホストで十分です。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`dist/` を任意の静的ホストに配置してください。

## 注意

- データは **そのブラウザ・端末だけ** に残ります。キャッシュ削除で失われる可能性があるため、重要な記録は JSON エクスポートを推奨します。
- カメラ利用には HTTPS または localhost が必要です。
